# StockPro Angular Frontend

Angular conversion of the StockPro React frontend.

It keeps the same backend API base URL:

```txt
http://localhost:8080/api/v1
```

## Run

Use Node 22 LTS (Angular 18 does not support Node 24):

```bash
nvm use
```

```bash
npm install
npm start
```

## Build

```bash
npm run build
```
